# DeepSeek Harness 运行模式

## 一、四种运行模式

### 1.1 Standard 模式（默认）

完整的编码 agent 工具集：
- 文件编辑（Read/Write/Edit）
- Shell 执行（Bash/PowerShell）
- 文件搜索（Grep/Glob）
- Web 搜索/获取
- 技能（Skills）
- 计划模式（Plan Mode）
- 目标管理（Goals）
- 子代理（Subagents）
- 工作流（Workflows）
- Todo 追踪

```bash
dsh web                    # Web UI
dsh --profile headless     # Headless
```

### 1.2 Code 模式

所有 Standard 模式能力，加上 Code Mode SDK：
- 模型可以生成 TypeScript 程序来编排多轮工具调用
- 适合复杂的多步骤任务

### 1.3 Minimal 模式

最小化的编码 agent：
- 仅 Shell 工具 + 文件编辑器
- 用于基准测试模型在最小环境中的表现

### 1.4 Creator 模式

用于创建自定义 agent 预设：
- 所有 Standard 模式能力
- 运行时检查（inspect current runtime）
- 插件实验（test Cordis plugins in memory）
- 预设编写指导（preset-authoring guidance）

## 二、Profile 运行模式

### 2.1 Web Profile

```bash
dsh web
# 或
pnpm dsh web
```

- 启动 Web UI 服务器（默认 http://127.0.0.1:3080）
- 加载 `dsh-base` + `dsh-web-app` bundles
- 支持 `--patch` 加载额外配置
- 支持 `--no-open` 不自动打开浏览器

### 2.2 Headless Profile

```bash
dsh --profile headless "task description"
```

- 无服务器的一次性任务运行
- 完成后直接退出
- 适合 CI/CD 和脚本化使用

### 2.3 自定义 Profile

```bash
dsh --profile my-profile web
```

在 `$DSH_HOME/profiles/my-profile/` 下定义配置。

## 三、启动参数

### 3.1 常用参数

| 参数 | 说明 |
|:--|:--|
| `web` | 启动 Web UI |
| `--profile <name>` | 指定 profile |
| `--patch <file>` | 加载 patch 配置 |
| `--no-open` | 不自动打开浏览器 |
| `--dump-config` | 输出完整配置树 |
| `--mode <mode>` | 指定运行模式 |

### 3.2 CLI 命令

| 命令 | 说明 |
|:--|:--|
| `dsh web` | 启动 Web UI |
| `dsh plugin --profile <name> add <pkg>` | 安装插件 |
| `dsh plugin --profile <name> list` | 列出插件 |
| `dsh --dump-config` | 查看配置 |

## 四、会话管理

### 4.1 会话存储

- 会话日志存储在 `$DSH_HOME/sessions/`
- 格式：JSONL（每行一个 SessionEvent）
- 支持 JSONL 和 SQLite 后端

### 4.2 会话操作

- **Resume**：恢复已有会话
- **Fork**：从会话分叉新会话
- **Search**：全文搜索会话历史
- **Replay**：重放会话事件

### 4.3 Trajectory 视图

Web UI 中的 Trajectory 视图可以：
- 按来源检查事件记录
- Resume、fork、search、replay 都操作同一事件流
- 查看每个 tool call 的输入输出

## 五、工作区

### 5.1 选择工作区

Web UI 启动后需要选择工作区目录：
- Agent 在该目录下执行文件操作
- 工作区选择通过 `ctx.directoryPicker` 管理

### 5.2 工作区隔离

- 每个会话绑定一个工作区
- 文件系统工具受限于工作区范围
- 沙箱模式下进一步隔离
