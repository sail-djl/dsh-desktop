# DeepSeek Harness 事件系统

## 一、事件分发模式

Cordis 事件有四种分发模式：

| 模式 | 等待? | 执行顺序 | 有返回值? |
|:--|:--|:--|:--|
| `emit` | 否 | listener 按注册顺序观察 | 否 |
| `waterfall` | 否 | around-middleware 模式 | 是 |
| `parallel` | 是 | 所有 listener 并行 | 否 |
| `serial` | 是 | listener 按注册顺序 | 是 |

### waterfall 语义

`ctx.waterfall` 是 around-middleware 模式。listener 收到 `(...args, next)`：
- 调用 `next()` 将控制委托给下一个 listener
- 返回而不调用 `next()` 则短路链

## 二、Session Events（持久化事实）

追加到日志，通过 `session/event` 广播。必须存活 reload。

| 事件 | 分发 | 说明 |
|:--|:--|:--|
| `turn/start` | emit | Turn 开始 |
| `turn/end` | emit | Turn 结束 |
| `step/start` | emit | Step 开始（一次模型请求） |
| `step/end` | emit | Step 结束 |
| `user/message` | emit | 用户消息写入日志 |
| `assistant/chunk` | emit | 模型输出片段（流式） |
| `assistant/message` | emit | 完整模型消息 |
| `tool/call` | emit | 工具调用请求 |
| `tool/result` | emit | 工具执行结果 |

---

## 三、Agent Events（实时协调）

携带活跃 Agent 实例，不持久化。

| 事件 | 分发 | 说明 |
|:--|:--|:--|
| `agent/created` | emit | Agent 创建 |
| `agent/disposed` | emit | Agent 销毁 |
| `agent/status` | emit | 状态切换（idle/running） |
| `agent/session-start` | emit | 会话开始 |
| `agent/inbox/inserted` | emit | 消息插入 inbox |
| `agent/inbox/claimed` | emit | 消息被 claim |
| `agent/inbox/discarded` | emit | 消息被丢弃 |
| `agent/error` | emit | 错误发生 |
| `agent/pre-step` | waterfall | 拒绝或替换 step 消息（权威决策点） |
| `agent/request` | waterfall | 替换调用配置 |
| `agent/request-error` | waterfall | 请求失败恢复 |
| `agent/turn-stopping` | serial | Turn 即将关闭 |

### agent/pre-step 详解

这是 Turn 流程中的权威决策点：
- listener 可以重写 claimed 消息
- listener 可以拒绝消息（reject）
- 空的 first claim 仍会关闭 turn（记录尝试）

## 四、Capability Events（策略与适配器）

| 事件 | 分发 | 说明 |
|:--|:--|:--|
| `tools/pre-execute` | waterfall | 工具执行前拦截 |
| `tools/execute` | waterfall | 工具执行 |
| `tools/post-execute` | waterfall | 工具执行后处理 |
| `llm/stream` | waterfall | 围绕每个 streaming 模型调用 |
| `system-prompt/assemble` | waterfall | Prompt 装配 |
| `fs/write-intent` | emit | 文件写入意图 |
| `fs/observed` | emit | 文件系统变更观察 |
| `session/flush` | parallel | 会话刷新检查点 |

## 五、事件矩阵

### 生产者

| 生产者 | 产出事件 |
|:--|:--|
| `core/agent-loop` | `turn/*`, `step/*`, `agent/pre-step`, `agent/request`, `agent/turn-stopping` |
| `core/session` | `session/event`, `session/flush` |
| `llm/llm` | `llm/stream` |
| `core/tools` | `tools/pre-execute`, `tools/execute`, `tools/post-execute` |
| `core/system-prompt` | `system-prompt/assemble` |
| `fs/fs` | `fs/write-intent`, `fs/observed` |

### 消费者

| 消费者 | 监听事件 | 用途 |
|:--|:--|:--|
| `session/session` | 所有 session events | 持久化日志 |
| `compaction/` | `session/flush` | 上下文压缩 |
| `spill/` | `tool/result` | 大结果溢出存储 |
| `token-meter` | `assistant/chunk` | token 计量 |
| `telemetry/` | 多个事件 | 遥测上报 |
| `ui-*` 插件 | `session/event` | Web UI 渲染 |
