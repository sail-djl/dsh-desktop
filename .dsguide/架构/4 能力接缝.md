# DeepSeek Harness 能力接缝

## 一、Seam 模式

每个可替换能力（seam）由三个角色组成：

| 角色 | 说明 | 例子 |
|:--|:--|:--|
| **Service Definition** | 声明接口的 Cordis Service | `dsh-shell`（`ctx.shell`） |
| **Service Provider** | 实现该能力的具体插件 | `dsh-bash-local` / `dsh-bash-sandbox` |
| **Consumer** | 使用该能力的消费者 | `dsh-tool-bash`（面向模型的工具） |

**核心价值**：一次 provider 替换就能改变整个产品行为。

## 三、替换 Provider 的效果

| 替换 | 效果 |
|:--|:--|
| `dsh-bash-local` -> `dsh-bash-sandbox` | Shell 执行从本地切换到沙箱 |
| `dsh-fs-local` -> `dsh-fs-e2b` | 文件系统从本地切换到 E2B 云沙箱 |
| `dsh-llm-deepseek` -> `dsh-llm-pi-ai` | 模型从 DeepSeek 切换到多 provider |
| `dsh-session-jsonl` -> `dsh-session-sqlite` | 会话存储从文件切换到数据库 |
| `dsh-sandbox-bwrap` -> `dsh-sandbox-landlock` | 沙箱从 bwrap 切换到 Landlock |
