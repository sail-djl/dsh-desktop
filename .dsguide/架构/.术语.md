# DSH 术语表

> DeepSeek Harness 框架中出现的所有专业术语解释。

---

## 核心概念

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Dsh** | DeepSeek Harness | 框架本名，Agent 执行引擎 + 插件编排系统 |
| **Cordis** | Cordis | DSH 的微内核，提供 Context、Fiber、Registry、Service 等基础能力 |
| **微内核** | Microkernel | Cordis 的设计哲学：核心只提供注册/发现/生命周期，所有能力由插件实现 |
| **Context** | Context | Cordis 的核心对象，所有服务/插件/工具都注册在 context 上 |
| **Fiber** | Fiber | Cordis 的插件生命周期单元，管理一个插件的 activate → active → dispose |

---

## 插件体系

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Plugin** | Plugin | 一个独立的功能单元，注册到 context 上 |
| **Bundle** | Bundle | 把一组插件打包为 npm 包 + `cordis.patch.yml`，profile 通过声明 bundle 加载 |
| **Patch** | Patch | `cordis.patch.yml` 中的覆盖/插入/禁用操作 |
| **Patch 层** | Patch Layer | 一层 cordis.patch.yml 的叠加，后层覆盖前层 |
| **Profile** | Profile | 一组 bundles + patches 的组合，定义一个 Agent 的完整能力集 |
| **Agent Preset** | Agent Preset | 通过 `agent.cordis.yml` 定义的 Agent 预设，决定工具集和提示词 |
| **Skill** | Skill | 可复用的能力资产，通常是一个 prompt 模板 + 工具定义 |
| **Rule** | Rule | Agent 必须遵守的约束，通过 prompt 注册或事件拦截实现 |
| **MCP** | Model Context Protocol | 标准化的模型上下文协议，用于连接外部系统 |

---

## Patch 操作

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **insert** | Insert | 在插件树中插入新行（新插件） |
| **override** | Override | 用 id 匹配已有插件，覆盖其 config |
| **disabled** | Disabled | 用 id 匹配已有插件，将其禁用 |
| **cordis:group** | Group | 虚拟容器，包裹子插件，创建共享 realm |
| **isolate** | Isolate | group 内的 realm 隔离声明，防止跨 preset 冲突 |

---

## 能力接缝 (Seam)

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Seam** | Seam | 可替换的能力接口，定义契约 + 实现 + 消费 |
| **Service Definition** | Service Definition | 声明接口的 Cordis Service（如 `ctx.shell`） |
| **Service Provider** | Service Provider | 实现该能力的具体插件（如 `dsh-bash-local`） |
| **Consumer** | Consumer | 使用该能力的消费者（如 `dsh-tool-bash`） |
| **接缝切换** | Seam Switching | 替换 provider 改变整个产品行为（如 local → sandbox） |

---

## Session 与 Agent

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Session** | Session | 一次对话会话，包含消息流、工具调用、状态 |
| **SessionEvent** | SessionEvent | Session 中产生的事件（turn/start、tool/call 等） |
| **Agent Loop** | Agent Loop | Agent 的核心循环：接收消息 → 选择工具 → 执行 → 返回结果 |
| **Turn** | Turn | Agent Loop 的一轮：一次 LLM 调用 + 工具执行 |
| **Workspace** | Workspace | 工作区，按目录路径分组 session |
| **Persona** | Persona | Agent 的系统提示词，定义角色和行为 |

---

## 工具与执行

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Tool** | Tool | 面向模型的工具，LLM 可调用的能力 |
| **Tool Catalog** | Tool Catalog | 当前 agent 可用的工具列表 |
| **Tool Execution** | Tool Execution | 工具的实际执行过程 |
| **Tool Result** | Tool Result | 工具执行后返回给 LLM 的结果 |
| **Code Mode** | Code Mode (PTC) | 模型写 TypeScript 程序，一次执行多步操作 |
| **Presentation** | Presentation | Code Mode 的展示层，工具调用的 UI 呈现 |

---

## 上下文管理

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **System Prompt** | System Prompt | 系统提示词，包含 persona + prompt sections |
| **Prompt Section** | Prompt Section | system prompt 的可插拔片段，由插件注册 |
| **Compaction** | Compaction | 上下文压缩，当 token 超限时裁剪历史消息 |
| **Tool Result Pruner** | Tool Result Pruner | 工具结果修剪器，裁剪过长的工具输出 |
| **Context Pressure** | Context Pressure | 上下文压力指标，用于判断何时触发压缩 |
| **Spill** | Spill | 溢出机制，将大量数据写入文件而非留在上下文中 |

---

## 状态与持久化

| 术语 | 英文 | 说明 |
| :-- | :-- | :-- |
| **Projection** | Projection | Session 状态的投影视图（如 title、stats、goal） |
| **Persistence** | Persistence | Session 的持久化存储（JSONL / SQLite） |
| **Checkpoint** | Checkpoint | 会话检查点，用于崩溃恢复 |
| **Session Projection Cache** | Projection Cache | Session 投影的缓存，加速 UI 渲染 |

## Web 与前端

| 术语 | 英文 | 说明 |

| **Boot Page** | Boot Page | 纯 DOM 的启动加载页，在 React 挂载前显示 |

| **Workspace Manager** | Workspace Manager | 工作区管理器，按目录分组 session |

## 部署与配置

| :-- | :-- | :-- |
| **DSH_HOME** | DSH Home | DSH 配置目录，默认 `~/.dsh` |
| **Profile Root** | Profile Root | profile 目录中的空根配置 `cordis.yml` |
| **Profile Patch** | Profile Patch | profile 目录中的 `cordis.patch.yml` |
| **Home Patch** | Home Patch | `$DSH_HOME/cordis.patch.yml`，机器本地覆盖 |

| **Recomposition** | Recomposition | 编辑 patch 文件后的实时重组（HMR 热重载） |
