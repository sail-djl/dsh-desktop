# DeepSeek Harness 插件开发

## 一、插件类型

### 1.1 Service 类插件

```typescript
import { Service } from '@deepseek-ai/cordis'

class MyService extends Service {
  constructor(ctx: Context) {
    super(ctx, 'myService')
  }

  // 服务方法
  doSomething() { ... }
}

export default MyService
```

### 1.2 函数插件

```typescript
export const name = 'myPlugin'
export const inject = ['serviceA', 'serviceB']

export function apply(ctx: Context) {
  ctx.effect(function* () {
    // 注册内容
    yield () => { /* 卸载清理 */ }
  })
}
```

### 1.3 声明式插件（cordis.yml）

```yaml
- id: my-plugin
  name: '@scope/my-plugin'
  config:
    option1: value1
    option2: value2
```

## 二、插件注册

### 2.1 工具注册

```typescript
// 在 ctx.tools 上注册面向模型的工具
ctx.tools.register({
  name: 'my_tool',
  description: 'My custom tool',
  parameters: { ... },
  async execute(params) {
    // 工具逻辑
    return result
  }
})
```

### 2.2 Prompt Section 注册

```typescript
ctx.systemPrompt.register({
  name: 'my-section',
  priority: 100,
  async getSections() {
    return [{ content: 'My custom prompt section' }]
  }
})
```

### 2.3 事件监听

```typescript
// 观察事件
ctx.on('agent/pre-step', (event) => {
  // 处理 pre-step 事件
})

// waterfall 模式（around-middleware）
ctx.waterfall('tools/execute', async (event, next) => {
  // 前置处理
  const result = await next()
  // 后置处理
  return result
})
```

### 2.4 LLM 适配器注册

```typescript
ctx.llm.registerAdapter({
  name: 'my-provider',
  async complete(request) {
    // 调用模型 API
    return response
  },
  async *stream(request) {
    // 流式响应
    yield chunk
  }
})
```

## 三、Bundle 插件

### 3.1 package.json 声明

```json
{
  "name": "@scope/my-bundle",
  "dsh": {
    "bundle": {
      "patch": "./cordis.patch.yml"
    }
  }
}
```

### 3.2 cordis.patch.yml

```yaml
- id: my-service
  name: '@scope/my-plugin'
  config:
    key: value
```

### 3.3 安装 Bundle

```bash
# 通过 CLI 安装
dsh plugin --profile web add @scope/my-bundle

# 或手动添加到 profiles/web/package.json
```

## 四、Agent Preset

### 4.1 定义 Preset

在 `$DSH_HOME/.agent-presets/<name>/agent.cordis.yml`：

```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    text: |-
      You are a helpful assistant.

- id: tool-bash
  name: '@deepseek-ai/dsh-tool-bash'

- id: tool-fs
  name: '@deepseek-ai/dsh-tool-fs'
```

### 4.2 使用 Preset

在 `settings.yaml`：
```yaml
agent-presets:
  default: my-preset
```

或在会话中切换。

## 五、扩展点速查

| 目标 | 机制 |
|:--|:--|
| 添加模型 provider | `ctx.llm` 注册 adapter |
| 添加工具 | `ctx.tools` 注册 |
| 添加 shell 后端 | `ctx.shell` 注册 |
| 添加终端后端 | `ctx.terminals` 注册 |
| 添加文件系统 | `ctx.fs` 注册 provider |
| 添加沙箱 | `ctx.sandbox` 注册后端 |
| 添加人类命令 | `ctx.commands` 注册 |
| 添加后台任务 | `ctx.jobs` 注册 |
| 拦截工具执行 | `tools/*` 事件 |
| 拦截模型请求 | `agent/request` 事件 |
| 拦截 Turn | `agent/pre-step` 事件 |
| 添加 Prompt Section | `ctx.systemPrompt` 注册 |
| 添加持久化 | 扩展 `SessionEventMap` |
| 添加 Web UI Tab | `ctx.slots.register()` |

## 六、调试

### 6.1 查看配置树

```bash
dsh --profile web --dump-config
```

### 6.2 Creator 模式

Creator 模式允许运行时检查、插件实验和预设编写：

```bash
dsh --profile web --mode creator
```

### 6.3 日志

日志输出到 stdout，包含插件加载、事件分发、工具执行等信息。
