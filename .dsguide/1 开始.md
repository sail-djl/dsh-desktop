# DeepSeek Harness

## 项目概述

DeepSeek Harness (`dsh`) 是由 DeepSeek AI 开发的开源 Agent 框架。核心理念：**Agent = Model + Harness**，模型是灵魂，Harness 让 Agent 理解环境、使用工具、在真实场景中工作。

一切皆插件（Everything is a plugin），基于 [Cordis](https://github.com/cordiverse/cordis) 微内核构建，插件可随时替换或重组，无需修改框架源码。

## 核心特性

- **插件化架构**：模型、工具、技能、会话、沙箱、存储、UI 全部是插件
- **Cordis 微内核**：只负责插件的加载、卸载和依赖管理
- **多种运行模式**：Standard / Code / Minimal / Creator
- **可追溯性**：所有模型看到的内容都记录在 append-only 的 Session Log 中
- **Host/Client 分离**：TypeScript 双聚合架构，服务端和客户端独立构建

## 架构概念

- **Profile**：命名的插件组合，存储在 Harness home 目录
- **Bundle**：分发格式，包含 Cordis 配置行和挂载的代码
- **Patch**：通过 `cordis.patch.yml` 替换或插入插件配置
- **Seam**：可交换的能力接口（Service Definition + Provider + Consumer）
