# DeepSeekHarness 配置说明

## 核心配置

| 配置项 | 值 | 说明 |
|:--|:--|:--|
| 包名 | `@deepseek-ai/dsh-root` | monorepo 根包名 |
| 版本 | 0.1.1-rc.2 | 开发者预览版 |
| 许可证 | MIT | 开源协议 |
| 模块类型 | ESM (`"type": "module"`) | ES 模块 |
| 包管理器 | pnpm@11.7.0 | 锁定版本 |
| Node.js 引擎 | ^22.19.0 或 >=24.0.0 | 运行时要求 |

## Workspace 配置

```json
"workspaces": [
  "vendor/*",
  "packages/*/*",
  "native/landlock-run",
  "native/landlock-run/packages/*",
  "apps/*",
  "website"
]
```

## 运行时配置

### 环境变量

| 变量 | 必填 | 说明 |
|:--|:--|:--|
| `DEEPSEEK_API_KEY` | 是 | DeepSeek API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | 自定义 API 地址 |

### Profile 配置

- `web`：Web UI 模式（含完整 Web 服务器）
- `headless`：无服务器的一次性运行模式

### 配置查看

```bash
# 查看当前配置树
pnpm dsh --profile web --dump-config
```

## 构建配置

| 配置项 | 说明 |
|:--|:--|
| TypeScript | 6.0.3+ |
| tsdown | 0.22.2+ (打包工具) |
| Vite | 6.4.3+ (Web 前端构建) |
| Vitest | 4.1.8+ (测试框架) |
| oxlint | 1.76.0+ (代码检查) |

## TypeScript 配置

| 文件 | 作用 |
|:--|:--|
| `tsconfig.json` | 解决方案根，引用两个聚合 |
| `tsconfig.host.json` | Host 聚合 (服务端) |
| `tsconfig.client.json` | Client 聚合 (客户端) |
| `tsconfig.base.json` | 共享编译选项和 paths 映射 |
| `tsconfig.base.client.json` | 浏览器编译设置 (JSX, DOM) |

## 插件配置

通过 `cordis.yml` 或 `cordis.patch.yml` 配置插件：

```yaml
# 示例：配置模型适配器
- id: deepseek-adapter
  model: deepseek-v4-pro
  apiKey: ${DEEPSEEK_API_KEY}
```

## 相关文件

- `package.json` — 项目配置和脚本
- `pnpm-workspace.yaml` — workspace 定义
- `vitest.config.ts` — 测试配置
- `.oxlintrc.json` — lint 配置
- `lefthook.yml` — Git hooks 配置
