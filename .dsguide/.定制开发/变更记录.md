### 2026-09-01：Preset 预设定制

**目的**：将百洲自定义的 Agent Preset 加入 shipped presets，使其随项目启动自动可用。

**变更内容**：

1. 从 `apps/cli/config/agent-presets/` 复制3个 preset 到 `packages/preset/agent-presets/presets/`：
   - `bzcode/` — 百洲开发者模式（order: 0）
   - `bzcode-haiyu/` — 百洲海渔开发者（order: 1）
   - `bzcode-shuili/` — 百洲水利开发者（order: 2）

2. 调整内置 preset 的 order 以确保自定义排在前面：
   - standard: 1 → 3
   - ptc: 2 → 4
   - minimal: 3 → 5
   - cordis: 4 → 6

**涉及文件**：

**注意**：
- 原始 preset 源文件保留在 `apps/cli/config/agent-presets/` 作为开发参考
- `bzcode-haiyu` 和 `bzcode-shuili` 包含 MCP Server 配置（含密码），注意安全

### 2026-09-01：Clean 脚本更新

**目的**：防止 clean 脚本将 presets 目录误判为危险孤儿目录。

**变更内容**：
`scripts/clean.ts` 第7行，`knownOrphanEntries` 新增 `presets`：
```typescript
// 变更前
const knownOrphanEntries = new Set(['node_modules', 'lib', '.typecheck'])
// 变更后
const knownOrphanEntries = new Set(['node_modules', 'lib', '.typecheck', 'presets'])
```

**原因**：
- clean 脚本扫描 `packages/` 下无 `package.json` 的目录时，会检查剩余条目是否为已知安全目录
- `presets` 目录下的 preset 子目录（bzcode 等）不在原生已知列表中
- 添加后即使 `agent-presets` 的 `package.json` 被意外删除，clean 也不会报错

**涉及文件**：`scripts/clean.ts`
