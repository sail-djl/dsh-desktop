# MCP 包层 (packages/mcp/)

> 版本: 0.1.1-rc.2
> 仓库: https://github.com/deepseek-ai/deepseek-harness (directory: packages/mcp)

## 包概述

DSH 的 MCP (Model Context Protocol) 集成层。将外部 MCP Server 的工具注册到 DSH 工具注册表，让 LLM 可以像调用内置工具一样调用外部工具。

## 子模块结构

```

├── mcp-client/           ← @deepseek-ai/dsh-mcp-client

│       └── fixture-server.ts
├── README.md

```

## 关键依赖

| 包 | 用途 |
| :-- | :-- |
| `@modelcontextprotocol/sdk` | MCP SDK（Client + Transport） |
| `@deepseek-ai/cordis` | 微内核（插件生命周期） |
| `@deepseek-ai/dsh-tools` | DSH 工具注册表 |
| `@deepseek-ai/dsh-attachment` | 图片附件处理 |
| `@deepseek-ai/dsh-llm` | 模型能力验证 |
| `@deepseek-ai/schemastery` | 配置 Schema 验证 |

## 核心能力

| 能力 | 说明 |
| :-- | :-- |
| stdio 连接 | 通过子进程连接本地 MCP Server |
| SSE 连接 | 通过 Streamable HTTP 连接远程 MCP Server |
| 工具发现 | 自动获取 MCP Server 的工具列表 |
| 工具注册 | 注册到 DSH ctx.tools，模型可直接调用 |
| 自动重连 | 指数退避重连策略 |
| 工具列表变化 | 自动 re-sync |
| 图片处理 | MCP 返回的图片经验证后注入 LLM |

## 接入示例

### 示例 1：连接 Redis MCP Server

```yaml
# cordis.patch.yml
- insert:
    - id: mcp-redis
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        transport: stdio
        serverName: redis
        command: npx
        args: ['-y', '@modelcontextprotocol/server-redis']
        env:
          REDIS_URL: redis://192.168.1.98:6379
          REDIS_PASSWORD: bz@2026++
        toolCallTimeoutMs: 30000
```

模型可调用：
- `mcp__redis__get_key` — 获取 Redis 键值
- `mcp__redis__set_key` — 设置 Redis 键值
- `mcp__redis__list_keys` — 列出匹配的键

### 示例 2：连接 GitLab MCP Server

```yaml
- insert:
    - id: mcp-gitlab
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        transport: stdio
        serverName: gitlab
        command: npx
        args: ['-y', '@modelcontextprotocol/server-gitlab']
        env:
          GITLAB_TOKEN: ${GITLAB_TOKEN}
          GITLAB_API_URL: https://gitlab.company.com/api/v4
        toolCallTimeoutMs: 60000
        reconnect:
          enabled: true
          maxAttempts: 5
```

模型可调用：
- `mcp__gitlab__create_merge_request` — 创建 MR
- `mcp__gitlab__get_file_contents` — 读取文件
- `mcp__gitlab__list_projects` — 列出项目

### 示例 3：连接文件系统 MCP Server

```yaml
- insert:
    - id: mcp-fs
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        transport: stdio
        serverName: fs
        command: npx
        args: ['-y', '@modelcontextprotocol/server-filesystem', '/workspace']
```

模型可调用：
- `mcp__fs__read_file` — 读取文件
- `mcp__fs__write_file` — 写入文件
- `mcp__fs__list_directory` — 列出目录

### 示例 4：多 Server 同时接入

```yaml
# 同时连接 Redis + GitLab + 文件系统
- insert:
```

### 示例 5：远程 MCP Server (SSE)

```yaml
- insert:
    - id: mcp-remote
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        transport: streamable-http
        serverName: remote-api
        url: https://mcp-server.company.com/sse
        headers:
          Authorization: Bearer ${MCP_TOKEN}
        toolCallTimeoutMs: 120000
        failOnStartupError: true
```

### 配置要点

| 要点 | 说明 |
| :-- | :-- |
| serverName | 唯一命名空间，最多 32 字符，只允许 `[A-Za-z0-9_-]` |
| transport | `stdio` = 本地子进程，`streamable-http` = 远程 SSE |
| env | 敏感信息通过环境变量传入，不硬编码 |
| toolCallTimeoutMs | 单次调用超时，默认 60s |
| failOnStartupError | true = 启动失败阻断 profile 加载 |
| reconnect | 自动重连策略，指数退避 |
