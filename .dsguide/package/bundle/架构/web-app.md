# dsh-web-app Bundle

| 属性 | 值 |
| :-- | :-- |
| 包名 | `@deepseek-ai/dsh-web-app` |
| 路径 | `packages/bundle/web-app/` |
| 描述 | Web 浏览器界面：静态托管、前端组件、Web Server |
| 依赖数 | ~60 |

## cordis.patch.yml 注册的插件

**Host**: webserver, frontend-static, apiproxy, plugin-inventory, directory-picker-*
**Client UI**: client-connection, client-hmr, client-modules, client-runtime, client-ui-* (40+ 组件)
**Storage**: storage, storage-domain, storage-json
**Session**: session-projection-cache, session-log-export, session-stats, session-reference
**Runtime**: code-runtime-worker-thread, agent-presets, api-remotes, workspace
