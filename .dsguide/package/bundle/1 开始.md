# Bundle 层

> 版本: 0.1.1-rc.2
> 仓库: https://github.com/deepseek-ai/deepseek-harness (directory: packages/bundle)
> 许可证: MIT

## 包概述

DSH 插件束层，将一组插件打包为 profile 可引用的 bundle。每个 bundle 有 `cordis.patch.yml`，profile 通过声明 bundle 名字加载整套能力。

## 子模块结构

```
packages/bundle/
├── base/              ← @deepseek-ai/dsh-base (~65 依赖)
│   ├── package.json       包名、依赖
│   ├── cordis.patch.yml   基础插件树注册
│   ├── src/               index.ts, invariant.ts
│   └── tests/
│
├── web-app/           ← @deepseek-ai/dsh-web-app (~60 依赖)
│   ├── package.json       包名、依赖
│   ├── cordis.patch.yml   Web UI 插件层注册
│   ├── src/               index.ts, startup.ts, invariant.ts
│   └── tests/
│
└── headless/          ← @deepseek-ai/dsh-headless (~5 依赖)
    ├── package.json       包名、最小依赖
    ├── cordis.patch.yml   无头配置
    ├── src/               index.ts, startup.ts, invariant.ts
    └── tests/
```

## 三个 Bundle 对比

| 包名 | 依赖数 | 用途 |
| :-- | :-- | :-- |
| `@deepseek-ai/dsh-base` | ~65 | 基础层：Agent/LLM/Shell/FS/Session/Tool |
| `@deepseek-ai/dsh-web-app` | ~60 | Web UI 层：前端组件、Web Server、存储 |
| `@deepseek-ai/dsh-headless` | ~5 | 无头层：CI/CLI 一次性任务 |

## 关键依赖 (base)

| 类别 | 依赖 |
| :-- | :-- |
| Agent | dsh-agent, dsh-agent-loop, dsh-agent-default-model |
| LLM | dsh-llm, dsh-llm-deepseek, dsh-llm-pi-ai, dsh-api-gateway |
| Shell | dsh-shell-env, dsh-bash-sandbox, dsh-pwsh-sandbox |
| FS | dsh-fs-local, dsh-fs-sandbox, dsh-fs-observation-policy |
| Session | dsh-session, dsh-session-persistence-jsonl, dsh-session-projection |
| Tools | dsh-tool-bash/pwsh/fs/web/goal/skill/todo/workflow/subagent 等 |
