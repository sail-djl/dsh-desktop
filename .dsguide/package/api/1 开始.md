# packages/api/ — API 网关与远程调用层

## 概述

`api/` 是 DeepSeek Harness 的 Typert RPC 远程调用层，为 Host 与 Client 两侧的 Cordis 环境提供远程方法调用能力。Host 端分发请求到 Cordis 服务，Client 端提供类型安全的远程方法代理。

**特殊地位**：`api/remotes` 是仓库中**唯一刻意拆分**的包——Host 入口和 Client 入口分别编译，共享同一份转发事件名单。

## 包清单

| 包名 | ctx key | 职责 | 模式 |
|:--|:--|:--|:--|
| `dsh-api-gateway` | `ctx.typertGateway` (Host) / `ctx.remote` (Client) | Typert RPC endpoint 分发器 | Service |
| `dsh-api-remotes` | — | Remote BFF 组装 + Agent/Session 身份策略 | Plugin |

## 核心设计

1. **Typert RPC**：基于生成的 `InvocationDescriptor` 进行远程方法调用，支持严格模式和 SRC 回退
2. **双侧架构**：Host 入口提供分发器，Client 入口提供类型安全代理
3. **Connection 集成**：传输、请求关联、信任和响应封装交给 Connection 层
4. **事件转发**：Host 事件原样转发给 Client（无投影、无脱敏）

## 关键文件

- `gateway/src/index.ts` — `TypertGatewayService`（Host 分发器）
- `gateway/src/client/index.ts` — `ClientRemote`（Client 代理）
- `remotes/src/index.ts` — BFF 组装 + 事件转发断言
- `remotes/src/remote-events.ts` — 转发事件名单
- `remotes/src/agent-lookup.ts` — Agent/Session 身份解析策略
