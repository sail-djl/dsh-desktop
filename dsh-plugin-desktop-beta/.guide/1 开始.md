# DSH Desktop Beta

## 项目概述

`dsh-plugin-desktop-beta` 是 DeepSeek Harness Desktop 的 **Beta 抢先版** Electron 插件。在 Electron 中运行 DSH Desktop，同时参与 Cordis 插件组合。应用名称为 **DSH Desktop Beta**，与稳定版可共存安装。

Beta 版使用更新的 DSH runtime（`0.1.3-alpha.2`），包含实验性功能和前沿特性。

## 与稳定版的关键差异

| 项目 | Beta 版 | 稳定版 (dsh-plugin-desktop) |
|:--|:--|:--|
| 版本 | 2.0.5-beta.2 | 2.0.5 |
| DSH Runtime | 0.1.3-alpha.2 | 0.1.2-rc.1 |
| AppId | ai.deepseek.dsh.desktop.beta | ai.deepseek.dsh.desktop |
| 产品名 | DSH Desktop Beta | DSH Desktop |
| 额外依赖 | fs-ext, dsh-http-proxy, dsh-client-file-upload, node-gyp | — |
| 原生模块编译 | 有 `prepare:electron-native` | 无 |
| Windows 图标生成 | 无 generate-windows-app-icon | 有 |

## 核心功能

- **三种显示模式**：兼容模式（默认）/ 扩展模式 / 增强模式
- **Profile 多用户**：命名插件组合，支持多环境配置
- **自动更新**：Beta 通道独立更新
- **局域网访问**：可选绑定所有网络接口
- **原生终端**：桌面终端集成（macOS/Windows）
- **插件市场**：社区插件发现与安装
- **恢复机制**：三槽位健康检查点 + 恢复窗口
