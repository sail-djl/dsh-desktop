# .spec/ 模块 — 多品牌 Spec 配置与构建

## 概述

`.spec/` 是 `dsh-plugin-desktop-spec` 项目的**多变体构建配置目录**。它为同一套 DSH Desktop 源码提供多个品牌身份配置，使得一次代码库可以打包出多个独立安装的应用。

**核心理念**：源码共享，身份隔离。每个 Spec 变体通过 `configspec.yaml` 定义自己的 appId、产品名、品牌图标和 Agent 预设，构建脚本在编译/打包前临时替换配置，构建后自动恢复。

## 关键概念

### configspec.yaml

每个 Spec 变体的核心配置文件，包含三个区块：

| 区块 | 作用 | 示例字段 |
|:--|:--|:--|
| `identity` | Electron 应用身份 | `appId`, `productName`, `packageName`, `artifactName` |
| `brand` | 品牌视觉资源 | `appIcon`, `trayIcons` |
| `agentPresets` | Agent 预设控制 | `removeShippedPresets`（移除不需要的内置预设） |

### 两个变体

| 维度 | Code 版 | Work 版 |
|:--|:--|:--|
| **定位** | 开发岗编码 Agent | 产品岗工作 Agent |
| **appId** | `ai.deepseek.dsh.code.desktop` | `ai.deepseek.dsh.work.desktop` |
| **产品名** | 百洲DSH Code | 百洲DSH Work |
| **品牌色** | 薰衣草紫 `(230,215,255)` | 纯白 `(255,255,255)` |
| **保留预设** | bzcode（百洲编码） | 标准模式（功能完整） |
| **移除预设** | minimal, cordis | minimal, cordis, bzcode, bzcode-haiyu, bzcode-shuili |

### 构建时替换机制

构建脚本（`spec-build.ts` / `spec-dist.ts`）在执行构建前会临时修改以下内容，构建后全部恢复：

1. **package.json** — 临时替换 `name`、`build.appId`、`build.productName`、NSIS 配置
2. **cordis.patch.yml** — 将 `dsh-plugin-desktop` 引用替换为目标变体包名
3. **源码环境变量** — 在 `src/main.ts`、`src/profile.ts`、`src/desktop-plugins.ts` 中将 `process.env.DSH_SPEC_*` 替换为字面量
4. **品牌图标** — 将 `.spec/{name}/app-icon.png` 和 `build/` 复制到项目根 `build/`
5. **Agent 预设** — 从 `node_modules` 中临时移除不需要的 shipped 预设

所有修改都在 `try/finally` 中保护，确保异常时也能恢复原始状态。

## 与其他目录的关系

```
dsh-plugin-desktop-spec/          # 项目根（共享源码）
├── .spec/                        # ← 本目录：多品牌配置
│   ├── code/                     #   Code 版配置
│   └── work/                     #   Work 版配置
├── .guide/                       # 项目级 guide（DSH 更新、图标、打包指南）
├── src/                          # 共享 TypeScript 源码
├── scripts/
│   ├── spec-build.ts             # Spec 构建脚本
│   └── spec-dist.ts              # Spec 打包脚本
├── package.json                  # 共享 package.json（构建时临时修改）
├── cordis.patch.yml              # Cordis 插件组合（构建时临时替换包名）
└── tsdown.config.ts              # tsdown 构建配置（define 注入环境变量）
```

## 快速上手

```bash
# 打包 Code 版（开发岗）
node scripts/spec-build.ts code
node scripts/spec-dist.ts code

# 打包 Work 版（产品岗）
node scripts/spec-build.ts work
node scripts/spec-dist.ts work

# 生成托盘图标（换图标后执行）
py scripts/gen-spec-icons.py code
py scripts/gen-spec-icons.py work
```
