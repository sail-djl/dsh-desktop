# DSH Desktop 渲染进程架构

## 技术栈

| 技术 | 版本 | 用途 |
|:--|:--|:--|
| React | 18.3.1 | UI 框架 |
| TypeScript | 6.0.3 | 类型系统 |
| Tailwind CSS | 4.x | 样式 |
| shadcn | 4.18.0 | UI 组件库（基于 Radix UI） |
| lucide-react | 1.33.0 | 图标库 |
| Vite | 8.2.1 | Native UI 构建 |

## 组件层级

```
BrowserWindow
└── Web Carrier (HTTP/WS)
    └── 官方 DSH Web UI（上游 @deepseek-ai/dsh-web-app）
        ├── Desktop Frame Overlay（兼容模式 36px）
        │   └── AdvancedFrame.tsx / ExtendedFrame.tsx
        ├── Desktop Settings Section
        │   └── DesktopSettingsSection.tsx
        └── Desktop Terminal Settings
            └── DesktopTerminalSettingsAction.tsx
```

## 核心组件

| 组件 | 文件 | 说明 |
|:--|:--|:--|
| AdvancedFrame | `src/client/AdvancedFrame.tsx` | 高级模式窗口框架 |
| ExtendedFrame | `src/client/ExtendedFrame.tsx` | 扩展模式窗口框架 |
| ExtendedTitlebar | `src/client/ExtendedTitlebar.tsx` | 扩展模式标题栏 |
| DesktopNativeActions | `src/client/DesktopNativeActions.tsx` | 原生操作（最小化/关闭等） |
| DesktopSettingsSection | `src/client/DesktopSettingsSection.tsx` | 桌面设置面板 |
| DesktopTerminalSettingsAction | `src/client/DesktopTerminalSettingsAction.tsx` | 终端设置 |
| Native UI 组件 | `src/native-ui/components/ui/` | shadcn 原生 UI 组件 |

## 客户端注入

通过 `package.json` 的 `dsh.client.inject` 声明注入的上游模块：

```json
{
  "inject": [
    "@deepseek-ai/dsh-api-remotes",
    "@deepseek-ai/dsh-client-connection",
    "@deepseek-ai/dsh-client-locale",
    "@deepseek-ai/dsh-client-ui-renderer",
    "@deepseek-ai/dsh-client-ui-settings",
    "@deepseek-ai/dsh-client-ui-theme"
  ]
}
```

## 状态管理

- 使用 DSH 上游的 Client Store（`@deepseek-ai/dsh-client-store`）
- Desktop 自有状态通过 Cordis 服务注入
- Layout 状态由 `layout-state.ts` 管理

## 关键服务

| 服务 | 文件 | 说明 |
|:--|:--|:--|
| Layout Service | `layout-service.ts` | 窗口布局管理 |
| Theme Presenter | `theme-presenter.ts` | 主题呈现 |
| Window Service | `window-service.ts` | 窗口生命周期 |
| Boot Health | `boot-health.ts` | 启动健康检查 |
| Directory Picker | `directory-picker.ts` | 目录选择器 |
| Environment | `environment.ts` | 环境信息 |
