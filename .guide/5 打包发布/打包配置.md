# DSH Desktop 打包配置

## 打包工具

- **electron-builder** 26.15.7
- **NSIS** 1.2.1（toolsets）
- **ASAR**：启用，部分依赖 unpack 到 `app.asar.unpacked`

## 打包配置位置

主配置在 `dsh-plugin-desktop/package.json` 的 `build` 字段。

## 通用配置

```yaml
appId: ai.deepseek.dsh.desktop
productName: DSH Desktop
asar: true
asarUnpack:
  - package.json
  - cordis.patch.yml
  - build/**
  - lib/**
  - node_modules/**
afterPack: ./scripts/verify-packaged-runtime.ts
electronFuses:
  runAsNode: true
directories:
  output: dist
  buildResources: build
```

## 平台配置

### Windows

```yaml
target: nsis (x64)
artifactName: DSH-Desktop-${version}-${arch}-Portable.${ext}
icon: build/app-icon.png

nsis:
  include: installer.nsh
  license: THIRD_PARTY_NOTICES.md
  oneClick: false
  perMachine: false
  allowElevation: true
  allowToChangeInstallationDirectory: true
  createDesktopShortcut: true
  createStartMenuShortcut: true
  differentialPackage: false
  artifactName: DSH-Desktop-${version}-${arch}-Setup.${ext}
```

### macOS

```yaml
target: dir
category: public.app-category.developer-tools
hardenedRuntime: true
icon: build/app-icon-mac.png
notarize: true
signIgnore: [\.pak$, \.dat$, \.wasm$]
mergeASARs: false
x64ArchFiles: (node-pty, node-addon-require-builtin, ripgrep, sharp, koffi)
```

### Linux

```yaml
target: dir
icon: build/app-icon.png
```

## 运行时闭包

打包后需要物理 unpack 的依赖：
- **pnpm**：内置包管理器
- **node-pty**：终端PTY
- **Windows ACL/native 文件**：平台特定二进制
- **sharp**：图像处理
- **koffi**：FFI 绑定

Profile fallback **不能**把符号链接指向虚拟 ASAR 路径。
