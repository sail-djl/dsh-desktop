## Monorepo 结构

```
dsh-desktop (Yarn workspace root)
├── dsh-plugin-desktop/     # 主包 - Electron Shell
├── dsh-community-market/   # 插件市场壳（文档阶段）
├── dsh-community-fabric/   # 社区 RFC（文档阶段）
└── deepseek-harness/       # 上游 DSH（pnpm，Git submodule，只读）
```

## 包依赖关系

```
dsh-plugin-desktop
  ├── depends → dsh-community-market
  ├── peerDeps → electron 43.3.0
  ├── deps → 130+ @deepseek-ai/dsh-* 包
  ├── deps → react, pnpm, sharp, koffi, adm-zip...
  └── devDeps → typescript, tsdown, vite, vitest, shadcn, tailwindcss...

dsh-community-market
  ├── peerDeps → @deepseek-ai/cordis + dsh-* 包
  ├── deps → ajv, semver, sharp, yaml
  └── devDeps → typescript, tsdown, vitest, testing-library...

dsh-community-fabric
  └── 仅文档，无运行时依赖
```

## 双包管理器策略

| 位置 | 包管理器 | 原因 |
|:--|:--|:--|
| 根 workspace | Yarn 4.18.0 | 统一管理 desktop 包 |
| deepseek-harness/ | pnpm | 保持上游不变 |

根 `upstream:*` 脚本通过 Yarn portable-shell 进入子模块后调用 Corepack。

## 关键设计决策

1. **Generation 模型**：每次 profile/模式切换 dispose 当前 generation，启动新 generation
2. **无 IPC 插件系统**：Electron API 不暴露给 Renderer
3. **DesktopDialogWindow**：独立沙箱化 BrowserWindow 处理确认/警告/错误
4. **Profile 定位**：名字和绝对目录由 `desktopProfiles.current` 提供，不从 argv/settings/URL 猜测
5. **Desktop Service 注册顺序**：在第三方插件可读取前注册
