# 本地启动

## 前置依赖

| 依赖 | 版本要求 | 说明 |
|:--|:--|:--|
| Node.js | ^22.19.0 或 >=24.0.0 | 运行时环境 |
| Yarn | 4.18.0+ | 包管理器（Berry） |
| Git | 2.26+ | 版本控制 + submodule |

## 从源码安装

```bash
# 1. 克隆仓库（含 submodule）
git clone --recurse-submodules https://github.com/anywhere-labs/deepseek-harness-desktop.git
cd deepseek-harness-desktop

# 如果已克隆但未初始化 submodule
git submodule update --init --recursive

# 2. 安装依赖
yarn install

# 3. 构建核心框架（deepseek-harness）
cd deepseek-harness
pnpm install
pnpm run build
cd ..

# 4. 构建桌面插件
yarn workspace dsh-plugin-desktop run build

# 5. 启动桌面应用
yarn workspace dsh-plugin-desktop run start
```

## 常用命令

| 命令 | 说明 |
|:--|:--|
| `yarn install` | 安装所有 workspace 依赖 |
| `yarn workspace dsh-plugin-desktop run build` | 构建桌面插件 |
| `yarn workspace dsh-plugin-desktop run dev` | 开发模式（构建 + 启动） |
| `yarn workspace dsh-plugin-desktop run start` | 启动桌面应用 |
| `yarn workspace dsh-plugin-desktop run test` | 运行测试 |
| `yarn workspace dsh-plugin-desktop run typecheck` | 类型检查 |
| `yarn workspace dsh-plugin-desktop run check` | 完整检查（构建+类型+测试+验证） |

## 开发模式

```bash
# 开发桌面插件（自动构建 + 启动）
yarn workspace dsh-plugin-desktop run dev

# 仅构建 Native UI（Vite）
cd dsh-plugin-desktop
vite build --config vite.native-ui.config.ts
```

## 打包发布

```bash
# Windows 打包
yarn workspace dsh-plugin-desktop run dist:win

# macOS 打包
yarn workspace dsh-plugin-desktop run dist:mac

# macOS 通用包（arm64 + x64）
yarn workspace dsh-plugin-desktop run dist:mac-smoke
```

## 环境变量

在项目根目录或 `dsh-plugin-desktop/` 下创建 `.env` 文件：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://...   # 可选，自定义 API 地址
```

## TypeScript 架构说明

项目使用双聚合架构（继承自 deepseek-harness）：

- **Host 聚合** (`tsconfig.host.json`)：服务端包
- **Client 聚合** (`tsconfig.client.json`)：客户端包

dsh-plugin-desktop 额外有：
- `tsconfig.json` — 主进程
- `tsconfig.client.json` — 客户端
- `tsconfig.native-ui.json` — 原生 UI
- `tsconfig.tests.json` / `tsconfig.tests.client.json` — 测试

## 排查问题

- Yarn Berry 需要 `corepack enable` 启用
- 首次安装后运行 `yarn workspace dsh-plugin-desktop run typecheck` 验证环境
- 如果 submodule 未初始化，运行 `git submodule update --init --recursive`
- `vendor/dsh-runtime/` 目录包含预构建的 tgz 包，确保不被 gitignore
