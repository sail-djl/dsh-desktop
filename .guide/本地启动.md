# 本地启动指南

## 前置依赖

| 依赖 | 版本要求 | 用途 |
|:--|:--|:--|
| Node.js | `^22.19.0` 或 `>=24.0.0` | 运行时 |
| Corepack | 内置 | 启用 Yarn 4.18.0 |
| Git | 最新 | 子模块 |

## 安装步骤

### 1. 初始化上游子模块

```bash
git submodule update --init --recursive
```

### 2. 启用 Corepack 并安装依赖

```bash
corepack enable
corepack yarn install --immutable
```

### 3. 启动开发模式

```bash
corepack yarn dev
```

此命令会先构建 desktop 包，然后启动 Electron。

## 常用命令

| 命令 | 说明 |
|:--|:--|
| `corepack yarn dev` | 构建 + 启动开发模式 |
| `corepack yarn build` | 构建 desktop 包 |
| `corepack yarn test` | 运行单元测试（vitest） |
| `corepack yarn typecheck` | 类型检查（5 个 tsconfig） |
| `corepack yarn check` | 完整 headless gate（构建+类型检查+测试+验证） |
| `corepack yarn upstream:build` | 构建上游子模块 |

## 平台打包

| 命令 | 平台 | 产物 |
|:--|:--|:--|
| `yarn dist:win` | Windows | NSIS 安装器 + Portable |
| `yarn dist:win-portable` | Windows | 仅 Portable |
| `yarn dist:mac` | macOS | Universal DMG |
| `yarn dist:mac-smoke` | macOS | 冒烟测试打包 |

## 验证脚本

| 命令 | 说明 |
|:--|:--|
| `yarn verify:closure` | 运行时闭包验证 |
| `yarn verify:cli` | CLI 运行时验证 |
| `yarn verify:loader` | Loader 启动验证 |
| `yarn verify:profile` | Profile 启动验证 |
| `yarn verify:licenses` | 许可证验证 |
| `yarn verify:operations` | 操作可靠性验证 |

## 平台打包验证

```bash
# Windows 完整验证
corepack yarn check:win-package

# macOS 完整验证
corepack yarn check:mac-package
```

## 注意事项

- 根 workspace 使用 Yarn + `nodeLinker: node-modules`
- 上游子模块保持自己的 pnpm workspace，不要在根目录直接调用 pnpm
- 构建产物输出到 `dsh-plugin-desktop/dist/`
- 所有构建和测试必须保持 headless 安全（不启动图形界面）
