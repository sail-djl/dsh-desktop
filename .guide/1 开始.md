# DSH Desktop

## 项目概述

DSH Desktop 是 DeepSeek Harness 的桌面端产品，基于 Electron 构建的 AI Agent 桌面客户端。核心理念：**Agent = Model + Harness**，通过 Cordis 微内核实现一切皆插件的架构。

本仓库是 monorepo 根目录，包含桌面端插件、社区市场、以及 `deepseek-harness` 核心框架子模块。

## 技术栈

| 类别 | 技术 |
|:--|:--|
| 语言 | TypeScript (ESM) |
| 运行时 | Node.js ^22.19.0 或 >=24.0.0 |
| 桌面框架 | Electron 43.3.0 |
| 包管理 | Yarn 4.18.0 (workspaces) |
| UI 框架 | React 18.3.1 + Tailwind CSS 4 |
| 构建 | tsdown + Vite + electron-builder |
| 测试 | Vitest |
| 内核 | Cordis (来自 deepseek-harness) |

## 仓库结构

```
dsh-desktop/
├── deepseek-harness/           # [git submodule] 核心 Agent 框架
│   ├── packages/               # 50+ 核心包（LLM/Shell/FS/Sandbox/Session 等）
│   ├── apps/                   # CLI + Web 入口
│   ├── vendor/                 # Cordis 微内核等第三方依赖
│   └── docs/                   # 架构文档
│
├── dsh-plugin-desktop/         # ⭐ 主力桌面插件（Electron shell）
│   ├── src/main/               # Electron 主进程（60+ 模块）
│   ├── src/client/             # 渲染进程 UI（React + Tailwind）
│   ├── src/native-ui/          # 原生窗口 UI（设置/对话框/向导等）
│   ├── tests/                  # 100+ 测试文件
│   └── cordis.patch.yml        # Cordis 插件配置补丁
│
├── dsh-plugin-desktop-beta/    # Beta 版桌面插件
├── dsh-plugin-desktop-spec/    # Spec 版桌面插件
├── dsh-community-market/       # 社区插件市场
├── dsh-community-fabric/       # 社区 Fabric
│
├── vendor/                     # 本地 vendor 包（dsh-runtime tgz）
├── patches/                    # Yarn patch 补丁
├── docs/                       # 产品文档（架构/FAQ/用户指南）
└── package.json                # monorepo 根配置
```

## 核心模块说明

| 模块 | 说明 | 包名 |
|:--|:--|:--|
| dsh-plugin-desktop | Electron 主插件，桌面端核心 | `dsh-plugin-desktop` |
| dsh-community-market | 插件市场客户端 | `dsh-community-market` |
| deepseek-harness | Agent 框架核心（submodule） | `@deepseek-ai/dsh-*` |

```yaml
workspaces:

```

## 关键依赖

- `@deepseek-ai/dsh-*` (0.1.2-rc.1) — 核心框架包，通过 `vendor/dsh-runtime/` 本地 tgz 引入
- `electron` (43.3.0) — 桌面运行时
- `dshmarket` (1.38.1) — 插件市场 SDK
- `react` (18.3.1) + `react-dom` (18.3.1) — UI 渲染
- `tailwindcss` (^4) + `lucide-react` — 样式和图标
