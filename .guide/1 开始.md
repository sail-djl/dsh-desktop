# DSH Desktop 项目概览与快速开始

## 1. 项目背景

DSH Desktop（DeepSeek Harness Desktop）是 DeepSeek Harness 的桌面客户端，基于 Electron 构建。它是一个薄的 Electron 宿主，在 main 进程中启动官方 DSH Host，Host 通过 HTTP/WebSocket Web carrier 提供 Web UI。

项目采用 **Cordis 插件化架构**，桌面端能力（窗口、托盘、profile、终端、更新）作为 Cordis 插件注入 Host，不另造 renderer IPC 插件系统，也不把 Electron API 暴露给页面。

**开源仓库**：https://github.com/anywhere-labs/dsh-desktop.git

## 2. 核心功能

- **Profile 管理**：多 profile 支持，profile 切换通过重启完成
- **Agent 能力**：内置 DeepSeek LLM Agent、工具调用、会话管理
- **插件生态**：Cordis 插件加载、第三方插件市场（规划中）
- **终端集成**：内置终端支持（bash/pwsh）
- **MCP 客户端**：Model Context Protocol 支持
- **跨平台打包**：Windows（NSIS 安装器）、macOS（Universal DMG）、Linux

## 3. 技术架构

| 层 | 技术 | 说明 |
|:--|:--|:--|
| 桌面宿主 | Electron 43.3.0 | 薄壳，仅负责窗口、托盘、原生适配 |
| 插件框架 | Cordis 4.0.1 | 微内核插件化，Host/Client 分层 |
| 渲染前端 | React 18.3.1 + TypeScript 6.0 | Web UI，不直接调用 Electron |
| 样式方案 | Tailwind CSS 4 + shadcn | 组件库 + 工具类优先 |
| 构建工具 | tsdown + Vite 8.2.1 | 包构建 + Native UI 构建 |
| 打包工具 | electron-builder 26.15.7 | ASAR + NSIS/DMG |
| 包管理 | Yarn 4.18.0（根） + pnpm（上游子模块） | 双包管理器隔离 |

## 4. 项目结构说明

```
dsh-desktop/                          # 根目录（Yarn workspace）
├── dsh-plugin-desktop/               # 主包：Electron shell + Cordis Host/Client 插件
│   ├── src/                          # 主进程源码（Electron main）
│   │   ├── main.ts                   # Electron 入口
│   │   ├── electron-runtime.ts       # Electron 运行时协调
│   │   ├── electron-shell-generation.ts  # 窗口/托盘 generation 管理
│   │   ├── electron-platform.ts      # 平台策略适配
│   │   ├── desktop-settings*.ts      # 设置管理
│   │   ├── desktop-terminal.ts       # 终端集成
│   │   ├── desktop-network.ts        # 网络/HTTPS
│   │   └── lan-*.ts                  # 局域网服务
│   ├── src/client/                   # 渲染进程源码（React 客户端插件）
│   │   ├── AdvancedFrame.tsx         # 高级窗口框架
│   │   ├── ExtendedFrame.tsx         # 扩展窗口框架
│   │   ├── DesktopSettingsSection.tsx    # 桌面设置面板
│   │   ├── advanced-shell.ts         # 高级 Shell 能力
│   │   └── extended-shell.ts         # 扩展 Shell 能力
│   ├── src/native-ui/               # 原生 UI 组件（shadcn）
│   ├── scripts/                      # 打包、发布、验证脚本
│   ├── build/                        # 构建资源（图标、安装器脚本）
│   └── docs/                         # 包级文档（service contract）
├── dsh-community-market/             # 插件市场壳（文档阶段）
├── dsh-community-fabric/             # 社区互操作 RFC（文档阶段）
├── deepseek-harness/                 # 上游官方 DSH（Git 子模块，只读）
├── docs/                             # 产品文档（架构、FAQ、用户指南）
├── .agents/                          # Agent 决策记录
└── .guide/                           # 项目上下文（本目录）
```

## 5. 开发环境要求

| 依赖 | 版本要求 | 用途 |
|:--|:--|:--|
| Node.js | `^22.19.0` 或 `>=24.0.0` | 运行时 |
| Yarn | 4.18.0（通过 Corepack） | 根 workspace 包管理 |
| Git | 最新 | 子模块管理 |
| electron-builder | 26.15.7（devDependency） | 打包 |

## 6. 关键约束

- `deepseek-harness/` 是固定版本的上游子模块，**不要**在 desktop 分支中修改其中的文件
- 上游子模块使用自己的 pnpm workspace，通过根 `upstream:*` 脚本间接操作
- 兼容模式必须运行上游默认客户端，不加覆盖
- 构建、类型检查、单测必须保持 headless 安全
