# DSH Desktop 产品设计

## 产品定位

DSH Desktop 是 DeepSeek Harness 的桌面客户端形态。它不是一个独立产品，而是 Harness 生态的桌面宿主层。

## 核心理念

1. **薄宿主**：Electron 仅负责窗口管理、托盘、原生适配，不承载业务逻辑
2. **插件化**：所有能力通过 Cordis 插件注入，桌面端自身也是一个 Cordis 插件
3. **不越界**：Electron API 不暴露给渲染页面，Renderer IPC 插件系统不存在
4. **上游不动**：`deepseek-harness/` 子模块保持原样，Desktop 的扩展只在 own 包中

## 产品模式

| 模式 | 说明 | Client 行为 |
|:--|:--|:--|
| 兼容模式 | 运行上游默认 Web 客户端 | 校验环境，通过 overlay slot 加入 36px Desktop frame |
| 扩展窗口 | 安装独立注册的 Desktop layout/sidebar | 禁用官方 root layout，承载官方 occupant |
| 增强模式 | 独立 root registration + 紧凑 caption | 保留独立 root 与内部 caption 几何 |

## 平台特性

- **macOS**：Universal 二进制（x64 + arm64）、原生材质窗口、Dock 图标、Hardened Runtime + 公证
- **Windows**：NSIS 安装器（可选安装目录、桌面快捷方式）、Portable 模式、ACL 沙箱
- **Linux**：Dir 模式（未打包安装器）
