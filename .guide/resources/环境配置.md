# 环境配置说明

## Node.js 版本

```yaml
engines:
  node: "^22.19.0 || >=24.0.0"
```

## Yarn 配置（.yarnrc.yml）

```yaml
enableScripts: false          # 禁用 postinstall 脚本
nmHoistingLimits: workspaces  # 限制 hoisting 到 workspace
nodeLinker: node-modules      # 使用 node_modules 而非 PnP
supportedArchitectures:       # macOS Universal 构建
  os: [current]
  cpu: [current, x64, arm64]
```

## Electron 版本

```yaml
peerDependencies:
  electron: "43.3.0"
```

## 构建输出

```
dsh-plugin-desktop/dist/     # electron-builder 输出目录
dsh-plugin-desktop/build/    # 构建资源（图标、安装器脚本）
```

## 环境变量

| 变量 | 说明 |
|:--|:--|
| `ELECTRON_RUN_AS_NODE` | electron-builder fuse 控制 |
| `NODE_ENV` | 开发/生产模式 |
